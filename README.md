Online Market

Descripción

Online Market es una tienda virtual para una tienda de barrio. El proyecto permite mostrar productos, consultar su precio y cantidad disponible, buscar productos y agregarlos a un carrito de compras.

También cuenta con un panel administrativo para gestionar los productos.

Funciones principales

* Mostrar productos disponibles.
* Buscar productos por nombre.
* Mostrar precio y cantidad disponible.
* Organizar productos por categoría.
* Agregar productos al carrito.
* Aumentar y disminuir cantidades.
* Eliminar productos del carrito.
* Crear productos.
* Editar productos.
* Eliminar productos.
* Mostrar un resumen del inventario.
* Validar los datos de los formularios.
* Mostrar mensajes de éxito y error.
* Adaptar la página para celulares y computadores.

Instalación

1. Descargar o clonar el proyecto.
2. Abrir la carpeta en Visual Studio Code.
3. Abrir la terminal.
4. Ejecutar:

npm install

5. Crear el archivo .env con las variables de Supabase.
6. Ejecutar:

node index.js

7. Abrir en el navegador:

http://localhost:3000

Panel administrativo

El panel administrativo se encuentra en:

http://localhost:3000/admin

Desde allí se pueden crear, editar y eliminar productos y consultar el resumen del inventario.

Base de datos

El proyecto utiliza Supabase para almacenar la información de los productos y las categorías.

Tabla productos

La tabla contiene:

* ID
* Nombre
* Precio
* Categoría
* Cantidad disponible

Tabla categorias

Almacena las categorías de los productos.

Uso

Los usuarios pueden ingresar a la página principal para consultar productos, utilizar el buscador y agregarlos al carrito.

El administrador puede ingresar al panel administrativo para gestionar los productos y consultar el inventario.
